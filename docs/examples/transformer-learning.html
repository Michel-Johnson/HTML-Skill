TRANSFORMER · LESSON 01

注意力不是“记忆”，而是在当前句子里找关系

先理解 Query、Key、Value 分别承担什么角色，再看公式会简单很多。

一句话：每个 Token 都会提出一个问题，再与所有 Token 的“标签”比较，最后按相关程度汇总信息。

① Query：我在找什么

当前 Token 生成一个查询向量，表达自己此刻需要的信息。

→
② Key：我能提供什么

其他 Token 提供可匹配的索引，用点积计算相关程度。

→
③ Value：真正取走的信息

相关度经过 Softmax 后，决定每个 Value 被汇总多少。

例子：“小猫趴在垫子上，因为它很累”
