TOKENIZER · FROM TEXT TO IDS

模型看到的不是文字，而是一串 Token ID

Tokenizer = 分词器：负责把人类文本切成模型词表中已经存在的片段。

输入：Transformers are unbelievably useful.

Transform4312ers388 are527 un653believ9174ably1602 useful5501.13

三种常见子词算法怎么选

算法核心思路优点常见模型
BPE
Byte Pair Encoding		反复合并最常一起出现的片段简单、稳定、训练快GPT 系列、Llama
WordPiece选择最能提升语言模型概率的合并对词形变化处理较好BERT
Unigram先准备大词表，再逐步删除贡献低的片段可以保留多种切分候选T5、SentencePiece

关键结论：Token 数量决定上下文长度与推理成本；同一句话换一种 Tokenizer，模型实际接收的序列可能完全不同。
