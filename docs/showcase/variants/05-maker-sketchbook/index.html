你的记录，默认留在本机。
不是塞进每个项目。所有项目共用一个用户数据目录，里面再按项目和会话分开。

      

        
不在你的 repo 里 :)
%USERPROFILE%\.codex\html-reply\
~/.codex/html-reply/


└─ workspaces/
   └─ <项目指纹>/
      └─ threads/
         └─ <会话 ID>/
            ├─ reply-<ID>.html
            ├─ history-<ID>.html
            ├─ archive/  ← 旧回复
            ├─ assets/   ← 页面资源
             └─ session.json
上面是默认位置。项目指纹来自绝对路径，移动项目后会生成新的项目分组；自定义设置会改变根目录。

      

    


    

      
分享之前，再看清边界。
页面留在本机，不等于自动加密、全面脱敏或模型完全离线。

      

          
✓
普通提交，不会顺手带走记录
数据位于仓库外，不依赖 .gitignore。发布器拒绝 Git 工作树内的数据目录；不可写就报错，不退回项目里。

          
!
但它不是加密保险箱
HTML 是普通文件。提问摘要会过滤常见密码与密钥，但正文、代码和图片不会全面自动脱敏。分享之前，还是要自己看一眼。

          
↓
表单答案去浏览器的下载位置
表单草稿会尝试写入浏览器本地存储；JSON 由浏览器下载，不在左边的历史目录里。需要手动把答案文件交给助手。

          
i
文件本地保存，模型不一定离线
页面没有内置上传接口，但生成时仍使用工作台的模型服务。“本地 HTML”不代表整段对话只在本机处理。
