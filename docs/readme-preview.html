CODEX SKILL · HTML REPLY

每次回答，
都是一页可读的 HTML

按用户明确要求，把 Codex 回复发布为独立、可刷新、带历史记录的页面；不同项目与 Session 使用外部数据目录完全隔离。

01 · CONSISTENT

统一视觉语言

固定软化包豪斯主题：浅色纸张、系统字体、宽画布、低圆角与克制配色。

02 · SESSION SAFE

Session 完全隔离

每个 Session 使用独立稳定页面、Prompt 状态和历史归档，不再相互覆盖。

03 · HISTORY

随时回看旧回复

右上角历史入口可回看原始 HTML；代码高亮、布局与内容保持完整。
